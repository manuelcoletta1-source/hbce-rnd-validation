# Project 001 — First Commercial Pilot

State: TARGET_SELECTION

## Objective

Obtain the first externally paid HBCE R&D Validation engagement.

## Preferred first engagement

Artifact Review or Evidence Reconstruction.

Initial target ticket:

EUR 350–650.

## Preferred domains

- robotics
- simulation and digital twins
- autonomous systems
- AI-agent execution
- provenance and evidence
- execution boundaries
- fail-closed control systems

## Acceptance criteria

The target should have:

1. a public or shareable technical repository;
2. a bounded engineering problem;
3. artifacts that can be reviewed or reconstructed;
4. maintainers able to act on findings;
5. enough technical value to justify a paid independent review.

## Success condition

One external project voluntarily pays for a bounded HBCE technical review.

Payment validation is distinct from technical validation.
