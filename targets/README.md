# HBCE R&D Validation — Target Radar

The Target Radar ranks potential external projects before outreach.

## Objective

Find projects where independent reconstruction, evidence validation,
negative-control design or execution-boundary review can create measurable value.

## Score

Maximum: 100

- Technical fit: 30
- Evidence surface: 25
- Maintainer activity: 15
- Review need: 20
- Commercial signal: 10

## Classification

80–100: PRIORITY_A

65–79: PRIORITY_B

50–64: WATCH

0–49: REJECT

A high score is not evidence that a project will pay.

Commercial willingness must be validated independently.
