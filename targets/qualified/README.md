# Qualified External Targets

Detailed pre-contact target analysis is retained privately.

The public repository may contain cryptographic anchors proving that an
independent technical review existed at a particular repository state.

A public anchor does not imply:

- a client relationship;
- a commercial engagement;
- a partnership;
- endorsement by the external project;
- permission to publish private correspondence;
- certification or conformity assessment.

Detailed findings are not published before responsible contact and review.
